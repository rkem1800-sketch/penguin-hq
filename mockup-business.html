When real numbers go in

GitHub Pages is public, so the real tab should not keep any money figures in this repo or in the public HTML.

Recommend option (a): serve the real numbers only from the existing PIN-protected Cloudflare Worker (or a sibling Worker), the same way the board, AR, and other Work trackers already work. The public page stays a shell with no amounts. RK signs in once with the PIN he already uses, and the Ops CEO, Bud, and Quinn bots can post updates with the write token they already have.

Option (b), Cloudflare Access with an email sign-in, is how Penguin Pricing is locked down (team penguin19.cloudflareaccess.com, one-time email code). I could not find a “Penguin Atlas” site. Access is stronger if other staff need their own logins, but that tab would have to live on a separate Pages or workers.dev site, not inside the public HQ app. For a tab RK opens in HQ, the PIN-protected Worker is the simpler fit.

This is a layout mockup. Every dollar, percent, date, and status on this page is invented. No customer data, no real books, no secrets. Follow-ups and the rest of HQ are unchanged. Questions on the privacy plan belong in the README.
